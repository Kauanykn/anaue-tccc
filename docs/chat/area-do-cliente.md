# Área do cliente

## Visão geral

A área do cliente é acessível somente após o login. Ela mostra os dados básicos da conta e o orçamento mais recente enviado por aquele usuário.

## Foto de perfil

Na área do cliente é possível escolher, alterar ou remover a foto de perfil.

Formatos aceitos: JPG, JPEG, PNG e WEBP. O arquivo pode ter no máximo 2 MB.

## Meus orçamentos

O menu **Orçamentos** abre a página **Meus orçamentos**. Nela o cliente acompanha todas as solicitações feitas pela própria conta. Solicitações de outras contas não são exibidas.

Quando não existem pedidos, a página informa que ainda não há orçamento solicitado e oferece um botão para iniciar uma nova solicitação.
