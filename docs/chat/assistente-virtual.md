# Assistente virtual

## Finalidade

O assistente virtual responde dúvidas sobre as funcionalidades e informações documentadas do site Anauê.

## Uso

O chat está disponível para usuários autenticados. Para abrir ou fechar o painel, use o botão flutuante de conversa. O histórico de mensagens é salvo separadamente para cada usuário.

## Limite de uso

Cada usuário pode enviar até 10 mensagens por minuto. Quando o limite é alcançado, é necessário aguardar antes de enviar novas perguntas.

## Limites das respostas

O assistente responde apenas com base na documentação do sistema. Quando não encontrar informação relevante, ele informa que a informação não está disponível na documentação.
