# Depoimentos e Avaliações
 
## Consultar avaliações
 
A página de depoimentos é pública e pode ser acessada por qualquer visitante.
 
Nela são exibidos:
 
- As avaliações cadastradas pelos clientes
- A média geral das notas
- O total de avaliações recebidas
- A distribuição de notas de 1 a 5 estrelas
 
## Criar uma avaliação
 
Para registrar uma avaliação, é necessário estar autenticado em uma conta.
 
Cada avaliação deve conter:
 
- Uma nota inteira de 1 a 5 estrelas
- Um comentário sobre a experiência
 
## Limite de avaliações
 
Cada conta pode possuir apenas uma avaliação.
 
Caso o usuário já tenha avaliado o buffet, a opção de criar uma nova avaliação não ficará disponível. Nesse caso, será possível apenas editar ou excluir a avaliação existente.
 
## Editar uma avaliação
 
O cliente pode editar a própria avaliação a qualquer momento.
 
Não é possível editar avaliações de outras pessoas.
 
## Excluir uma avaliação
 
O cliente pode excluir a própria avaliação.
 
Não é possível excluir avaliações de outras pessoas.
 
## Perguntas frequentes
 
### Preciso estar logado para avaliar?
 
Sim. Apenas usuários autenticados podem criar avaliações.
 
### Quantas avaliações posso fazer?
 
Cada conta pode possuir apenas uma avaliação.
 
### Posso mudar minha avaliação depois?
 
Cada conta pode deixar uma avaliação. Se mudar de ideia depois, é só editar a que já foi enviada 😊.
 
### Posso apagar minha avaliação?
 
Sim. Você pode excluir a avaliação vinculada à sua conta.
 
### Posso alterar a avaliação de outro cliente?
 
Não. Cada usuário pode gerenciar apenas sua própria avaliação.
 
### Como funciona a nota?
 
As avaliações utilizam notas inteiras de 1 a 5 estrelas.
 
### O que aparece na página de avaliações?
 
A página exibe os depoimentos cadastrados, a média das notas, o total de avaliações e a distribuição das notas por estrelas.
